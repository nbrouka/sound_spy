# 🎮 ЗВУКОВОЙ ШПИОН — Побег из лаборатории

2D стелс-игра на Pygame и Telegram-бот — сервис-помощник для неё.

**Суть игры:** агент должен добраться от старта до выхода из лаборатории за 120 секунд.
Охранники не видят, но слышат: любое передвижение агента создаёт звуковую волну,
и на Metal-плитках волна вдвое громче. Бегом можно уйти от погони быстрее,
но шум привлечёт всех охранников рядом.

---

## Структура проекта

```
sound_spy/
├── py_sound_spy/        # Игра: Pygame-приложение
│   ├── game.py          #   игровой цикл, состояния
│   ├── agent.py         #   агент: движение, звуковые волны
│   ├── blind_guard.py   #   охранник: FSM патруля и погони
│   ├── data_io.py       #   конфиги, логи, таблица рекордов
│   ├── ui.py            #   меню, HUD, экраны
│   └── README.md        #   подробное описание игры
│
└── py_bot/              # Telegram-бот: «Полевой аналитик»
    ├── bot.py           #   хендлеры, FSM, антифлуд
    ├── analytics.py     #   рекорды, статистика, ачивки
    ├── session.py       #   stateless JSON-сессии
    ├── config.py        #   токен из .env, пути
    └── README.md        #   подробное описание бота
```

Игра и бот работают в паре: игра пишет результаты сессий (`agent_logs.csv`)
и события (`game_flight.log`), бот читает эти выгрузки и даёт игрокам
таблицу лидеров, личную статистику, ачивки и уведомления.

## Быстрый старт

### Игра

```bash
pip install pygame
python3 main.py            # из корня репозитория
```

Управление: `WASD`/стрелки — движение, `Shift` — бег, `R` — перезапуск после финала.

### Бот

```bash
cd py_bot
pip install -r requirements.txt
cp .env.example .env       # вставить токен от @BotFather
python3 bot.py
```

Подробности установки, запуска, проверки и устранения проблем —
в [`py_bot/README.md`](py_bot/README.md).
